# Contexto para Agentes de IA (OpenWiki Standard)

Este repositório contém as configurações e infraestrutura para o projeto **Home Assistant**.

## Documentação do Projeto
A documentação estruturada do projeto está localizada na pasta `openwiki/`:
- Consulte `openwiki/overview.md` para entender o projeto.
- Consulte `openwiki/architecture.md` para detalhes sobre o ambiente Docker.

## Instruções para Edições
- As alterações de automações e configurações do Home Assistant devem ser feitas na pasta `config/`.
- Antes de commitar alterações no arquivo `configuration.yaml`, verifique a sintaxe YAML.
