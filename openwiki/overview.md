# Home Assistant Project Wiki

Bem-vindo ao repositório de automação residencial com Home Assistant.

## Estrutura do Projeto
- `config/`: Arquivos de configuração do Home Assistant (YAMLs, automações, scripts).
- `docker-compose.yml`: Definição do contêiner Docker para executar o serviço.
- `openwiki/`: Base de conhecimento para documentação e apoio a agentes de IA.
